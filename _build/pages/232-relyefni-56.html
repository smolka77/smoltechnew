Інвертор MFDC

Алюміній, нержавіюча й покрита сталь, різнорідні пари — сталь+алюміній.

TE700 / TE751

Мікропроцесорний контролер; двопозиційна педаль і дворучний старт.

Сервіс

Вільне опускання головки без тиску для налагодження.

Конструкція

Енергоефективний лінійний притиск

Модульна механіка як у AC-групи, джерело — інвертор. Вільне опускання головки без тиску для налагодження й сервісу.

  • Попередній хід циліндра, керований ключем
  • Водяне охолодження трансформатора й електродів
  • Захисний стоп негайно вимикає машину

Підбір

Коли обирати 56 кВА MFDC

Коли важливі енергія, електроди й важкозварювані матеріали при помірній потужності. Для більшого струму — 90–200 кВА.
